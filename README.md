# Telegram Business Backup Bot

Бот на aiogram 3.x сохраняет входящие сообщения подключённых Telegram Business-аккаунтов, сообщает владельцу об изменениях и удалениях, продлевает подписку через Crypto Pay и очищает архив сообщений старше 48 часов.

## Файлы

- `bot.py` — вся логика приложения с комментариями на русском;
- `requirements.txt` — зависимости;
- `.env.example` — пример значений окружения (токены в него не вписаны).

## Запуск

Требуется Python 3.10 или новее.

```bash
python -m pip install -r requirements.txt
export BOT_TOKEN="токен_от_BotFather"
export CRYPTO_PAY_TOKEN="токен_приложения_Crypto_Pay"
export ADMIN_ID="ваш_числовой_Telegram_ID"
python bot.py
```

На Bothost загрузите файлы проекта, установите зависимости из `requirements.txt`, укажите команду запуска `python bot.py` и добавьте три обязательные переменные окружения в панели хостинга. Файл `.env.example` автоматически не загружается: переменные нужно задать в окружении процесса.

Для testnet Crypto Pay дополнительно задайте:

```bash
export CRYPTO_PAY_API_URL="https://testnet-pay.crypt.bot/api"
```

По умолчанию база создаётся в `bot.db`. При необходимости задайте `DB_PATH` с постоянным путём хостинга.

## Подключение Telegram Business

1. Пользователь запускает бота командой `/start`.
2. Покупает подписку через `/pay` или кнопку «Купить подписку».
3. Нажимает «Подключить Telegram Business» либо открывает настройки Business в Telegram и выбирает этого бота как чат-бота.
4. Telegram присылает событие `business_connection`; бот сохраняет связь между `business_connection_id` и владельцем.

Важно: в Business-сообщении нет ID владельца Business-аккаунта, поэтому событие `business_connection` должно быть получено хотя бы раз. Связь хранится в SQLite и переживает перезапуск.

В aiogram 3.31.0 событие удаления регистрируется через `router.deleted_business_messages()`; его полезная нагрузка — `BusinessMessagesDeleted`.

## Команды

- `/start` — описание, предупреждение о конфиденциальности и подключение;
- `/pay` — счёт на 150 RUB с зачислением USDT;
- `/subscription` — срок действия подписки;
- `/support текст` — обращение администратору;
- `/reply USER_ID текст` — ответ администратора пользователю;
- `/admin` — статистика для администратора.

## Структура базы

Основные таблицы из задания:

- `business_messages` — содержимое и `file_id` сообщений;
- `users` — срок окончания подписки.

Две дополнительные служебные таблицы:

- `business_connections` — владелец и состояние каждой Business-связи;
- `paid_invoices` — идемпотентность оплаты, чтобы один счёт не продлил подписку дважды.

Создаются индексы по `message_id`, `chat_id`, составному ключу поиска и `timestamp`. Оплата активируется в транзакции `BEGIN IMMEDIATE`; повторное нажатие на проверку уже обработанного счёта не добавляет дни.

## Ограничения и эксплуатация

- Бот восстанавливает только сообщения, которые успел получить и сохранить после подключения и при активной подписке. Старые сообщения Telegram задним числом получить нельзя.
- Для медиа хранится Telegram `file_id`, а не локальная копия файла. Поддержаны фото, видео, документы, аудио, голосовые, видеосообщения, анимации и стикеры; несколько типов без `file_id` сохраняются текстовым описанием.
- События при неактивной подписке игнорируются, чтобы не расходовать ресурсы и не сохранять данные сверх оказанной услуги.
- Фоновая очистка запускается при старте и затем раз в сутки. Уже отправленные Telegram-уведомления и копии у администратора она не удаляет; это прямо указано в `/start`.
- Не публикуйте токены и SQLite-файл. Для рабочего запуска используйте отдельный Crypto Pay App и ограничьте его разрешения.
- Перед предоставлением сервиса пользователям настройте собственные условия и политику конфиденциальности, учитывающие применимое законодательство и правила Telegram/Crypto Pay.
